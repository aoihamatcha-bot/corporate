- A09の装飾は、既存の青・白・シアンを使った情報カードの重なりです。A05の比較案にも同じモチーフを使っています。
- A03・A04・A08はユーザーの採用指定に従って変更していません。これらに描かれた商品・風景を、今回の新しい構想図のカテゴリへ自動で描き替える処理は行っていません。

## レビュー一覧の操作

- 「改訂 / 日本語」「改訂 / English」「v1 / 前回案」で比較できます。
- 画像をクリックすると拡大します。保存リンクには現在表示している版が反映されます。
