## 3. 素材を用意するときの目安

以下は今回の制作に使う初期案であり、実素材の細部・表示サイズを見て調整します。

| 種別 | 推奨する準備内容 |
| --- | --- |
| 開発画面 | 元データはPNGで保存。Web用は横1600〜2000px程度から検討し、細かなUIの文字が読める解像度を優先。画面外に見出し・説明を置き、元の実画面を過度に作り変えない |
| 会社・仕事の写真 | 横長に切り出せる余白のある原本を1点。明るく自然な光、青・白を含む背景なら現行の事業画像と合わせやすい。実在の会社や人物の代わりになる架空写真は使わない |
| OGP画像 | 1200×630pxのPNG/JPEGを制作開始サイズにする。まず共通1枚、画像内に日本語の説明を入れる場合は英語版も検討。専用画像とメタデータをセットで実装する |
| サービス動画 | 実画面を使った短い説明動画、再生前の静止画、意味のある音声・説明がある場合は日英字幕を用意。ブランド演出用ループとは目的を分ける |
| ロゴ | 確定したSVG、必要なPNG書き出し、明るい背景／暗い背景での使用例を揃える。書体を変えるときもロゴは独立して扱う |
| Webフォント | 選んだ1ファミリーを中心に、使用する太さと文字範囲に合わせた配信データ・ライセンス記録を用意。検討用の小さな文字サブセットをそのまま本番の全文用フォントにはしない |

OGPはページ本文の画像とは別に設定する仕組みです。Next.jsでは `opengraph-image` / `twitter-image` または対応するメタデータで指定できます。[Next.js公式：共有画像](https://nextjs.org/docs/app/api-reference/file-conventions/metadata/opengraph-image)

動画には再生前の `poster` を設定でき、字幕は `<track>` で用意できます。[MDN：video](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/video)

- 日本語の見出し・本文：**端末内の Noto Sans JP**。

「Noto Sans JPとCSSに書いてある」ことと「どの端末でも同じ書体が表示される」ことは別です。この端末にはNoto Sans JPがあるため表示されていますが、他端末での実書体は今回未確認です。

## 6. 書体と合わせて検討したいデザイン

1. **本文を少し読みやすくする。** 事業説明をPCで16px程度、スマートフォンで15〜16px程度から検討。小さな案内文・ラベルは役割を見て12〜13px程度を目安にする。すべての文字を一律に拡大するのではなく、本文・見出し・補助情報の差を保つ。
2. **日本語見出しの字間を少し戻す。** `-0.02em`〜`0`程度を出発点に、書体と行の長さで調整。英語は日本語と別に字間・折り返しを確認する。数値はデザイン案であり、全要素への確定値ではない。
3. **見出し700・本文400を基本に、太さの役割を揃える。** LINE Seed JPを選ぶ場合は同じファミリーに英数字も揃える案から始める。日本語書体と英語書体を何種類も追加する必要は現段階ではない。
4. **長い見出しの改行を整える。** 「マーケティング・コラボレーション」などは意味のまとまりを保つ。特に日本語の句読点・中黒、英語の長い見出し、スマートフォンのメニューを確認する。
5. **文字の強さと画像の統一感をつなぐ。** 白地・青系グラデーション・現在の画像比率を軸にする。現在の濃色で抽象的なヒーローと、明るい2D事業画像との印象差は、将来のヒーロー素材選定で調整する余地がある。
6. **ロゴの形は独立させる。** 全体のフォント変更でMYSTENAの字形まで意図せず変わらないようにする。正式ロゴデータが決まったらSVGとして固定する方法を検討する。

書体を導入する場合、Webフォントの読み込み、読み込み前後の改行差、日英・スマートフォン、グラデーション帯と文字の位置を検証します。現在のアニメーションは実際の行の矩形を参照するため、フォント読み込み後の文字幅を前提にできるかを確認する必要があります。Next.jsはGoogle Fonts・ローカルフォントの配信を支援する `next/font` を用意しています。[Next.js公式：Font](https://nextjs.org/docs/app/api-reference/components/font)

ユーザー調整済みの文字グラデーションの余韻0.4〜0.6秒、黒へ戻る滑らかさ、サムネイルのホバー時のみの発火は、今回の字体検討による変更対象ではありません。
