## 制作・配信形式

- 生成イラストA03/A04/A08：内蔵 `image_gen` を各1回使用。CLI・外部APIのフォールバックは使っていません。既存の事業サムネイルを画風の参照にし、新しい場面を制作しました。プロンプトは [prompts](prompts/) に保存。
- 3点の原寸PNGはワークスペースの `.local/asset-proposals-v1/originals/` にコピーして保管。生成元ファイルの場所も [制作ファイル記録](evidence/asset-files.json) に記録。
- 生成画像は幅1600px以下のWebPに変換。色・形・内容の後加工は行っていません。
- UI構想図、事業図、共有画像、表紙、既存ロゴのデータ化はSVGで制作。文字はLINE Seed JP 400/700。ロゴ文字は現行表示に合わせたArial Blackのアウトラインです。
- `editable/` はテキスト編集用SVG。編集アプリには対象書体が必要です。`assets/` のSVGは文字をパス化してあり、フォントのインストールなしで同じ見た目を保てます。
- `fonts/` はこの固定原稿のレビュー一覧専用サブセットです。本番サイトの全文用フォントを置き換えるものではありません。[OFL](fonts/OFL.txt) と [取得元・ハッシュ](fonts/font-sources.json) を同梱しています。
- UI画面・商品モチーフは説明用のデザインです。実際の販売商品、提供機能、正式UI、実績を示すものではありません。日英の図には構想であることを表示しています。

- 実際の会社／代表者の写真は未提供。A03は架空の人物と仕事場を描いたイラストであり、実際の社員や会社を示す写真の代用にはしません。会社情報でイラストを使う場合はその位置付けを明確にします。
- 公開可能な制作実績（事業02・03・04）は実素材が揃ってから制作します。今回は採用済みの事業サムネイルと重複する「架空の実績」は増やしていません。

- ニュースA09は汎用の表紙だけを作成。実際の記事・日付・発表内容は追加していません。
- 提携先ロゴ、共同企画商品の実写真は、実際の関係と公開可能な素材が確認できてから用意します。
