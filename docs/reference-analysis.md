## 観察した事実

Chromiumで1440×900、390×844を操作した。PC/SPの動画と連続スクリーンショットは、公開リポジトリ外の引き渡し資料フォルダー `whatever-observation/` に保管。他社画像はこのリポジトリに含めない。

| 操作 | 実際に確認できたこと |
| --- | --- |
| 初回 | 左端の固定レールにメニューボタン。大きな動画領域と白い余白。 |
| メニューを開く | 色面が先行し、文字の一部を横に走る矩形の色・マスクが続く。背景全体にも色が残る状態を採取。 |
| 開いた後 | PCは大きな主項目と補助領域の左右配置。暗い中立背景＋白い文字の状態と、文字・背景に色のある状態の両方を実操作で確認。すべての操作で同じ色や順序になるとは断定しない。 |
| ホバー・フォーカス | Workのホバーで白い文字が水色系へ変化。Tab操作後の画面も採取。全項目の厳密なキーボード仕様は監査していない。 |
| 閉じる | 閉じるボタンで元ページへ復帰。採取したPC/SPのトップ位置ではscrollY=0→0。任意の深い位置や実機iOS全条件を証明するものではない。 |
| スマートフォン幅 | 主項目が1列となり、補助情報の量・位置が変化。縦スクロールで下部へ到達できる。 |
| スクロール・逆方向 | 初回領域から下へ移動し、逆方向に戻った画面を採取。通常のスクロールと余白の使い方を確認。 |
| ポインター移動・停止 | 移動後・停止後の画面を採取。速度に対応する減衰係数、光と残光の正確な計算式は未確認。 |
| OS動き抑制 | reduce設定で開いたメニューにも色が見える。静止画像だけから、すべてのアニメーションが停止したとは判断しない。 |

連続スクリーンショットのファイル名100/350/900は撮影の目標時刻。撮影完了の実経過はPC 500/903/1238ms、SP 233/471/1012msで、撮影処理の時間も含む。これをサイト自身の正確なアニメーション時間として流用していない。初期のagent-browser録画はffmpeg出力に失敗したため、PlaywrightでPC/SP動画を別途採取した。

使用ライブラリ名、ソースコード、内部実装、物理的な減衰係数は確認していない。見た目から推測したライブラリ名は記載しない。

## MYSTENAに採用する表現

- 深い青のヒーロー＋同梱の光の画像。読む領域は白・青白を中心にし、最後の領域で深い青へ戻す。
- 大きな英字メニューと日本語の補助ラベル。Skyを主役に、Irisをつなぐ明るい背景。全画面の色面と文字の色変化は分けて動かす。
- 原稿はサーバーHTMLに含め、最初から読める状態にする。色が先行し、短い左右移動、遅れた残光の順で初回のみ演出する。
- 英字カットインは900msの一度限りの移動。終了後は通常の文書フロー上の定位置。スクロール量を文字transformに結び付けない。
- 光と残光は別速度でポインターに追従。停止時に収束し、離脱時に減衰。requestAnimationFrameは必要な間だけ使用する。
- ネイティブdialogに明示的なTab循環を補い、背景操作を抑止。停止ボタンとOSの動き抑制を優先する。

## 採用しない表現

赤・濃紫の広い色面、長時間読みにくくなるマスク、参考サイトのロゴ・文言・画像・コード、Team/Careers/SNS/Newsletterの追加、スクロールを奪う固定区間、常時動作するWebGL、A/B比較UIは採用しない。

## 初期実装値と調整場所

`styles/tokens.css` が色と主要な時間・移動量の調整元。JavaScriptも同じCSS変数を読む。

| 対象 | 採用値（MYSTENA独自の実装値） |
| --- | --- |
| メニュー開く / 閉じる | 520ms / 320ms。閉じる側は操作復帰を早めるため当初の400〜700ms案より短くした |
| 項目の時間差 | 45ms |
| 本文 / カットイン | 780ms / 900ms |
| 色の先行 / 残光 | 920ms / 1200ms、残光の遅れ120ms |
| 通常の横移動 | PC56px / SP24px |
| 英字の横移動 | 90px |
| パレット | Sky=主役、Mint=About、Iris=Business、Apricot=Contact |

文字用の濃い青・青紫・青緑は背景用パステルから分離。WebGL依存を外し、CSS/WAAPIと収束するポインター処理に絞った。描画APIの失敗時にも本文を残す。

操作設計は[WAI-ARIA APG Modal Dialog](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)、文字の基準は[WCAG Contrast Minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)を確認した。
